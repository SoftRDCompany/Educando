# Educando
**Educando** es una plataforma educativa "No-Code" diseñada bajo un modelo Software como Servicio (SaaS). Ofrece un entorno visual *Drag & Drop* para construir cursos, sesiones interactivas, evaluaciones e integrar herramientas impulsadas por Inteligencia Artificial.

##  Jerarquía de Usuarios y Roles

1. **Super Administradores (Soft RD):** Control total de infraestructura y licencias corporativas.
2. **Cuenta Institución:** Espacio personalizado (*Whiteboard*) para escuelas o academias.
3. **Administradores Institucionales:** Asignación de profesores, analíticas globales y reportes.
4. **Profesores / Creadores:** Uso del *Toolbox* visual para crear sesiones, cuestionarios y ejercicios.
5. **Alumnos:** Consumo de contenidos, interacción con el Tutor Virtual y resolución de ejercicios.

---
##  Componentes Clave

* **Toolbox (Constructor Visual):** Bloques arrastables para presentaciones (PDF, video), quizzes dinámicos, ejercicios interactivos y reglas de avance (prerrequisitos).
* **Módulo de IA:**
  * *Asistente de Creación:* Generación de temarios y reactivos para profesores.
  * *Tutor Virtual:* Asistente conversacional en tiempo real para alumnos.
  * *Evaluación Inteligente:* Análisis automático de preguntas abiertas.

* **`backend/`**: Código fuente de la API y lógica del servidor.
